# 扫雷搜打撤 - 游戏设计文档

> 2026 TapTap GameJam 当前玩法方向
> 核心组合：经典扫雷地图 + 房间探索 + 搜打撤

---

## 一、核心概念

玩家从扫雷地图中心出生。左上角始终显示一张经典扫雷小地图：格子、数字、旗标、未知区域、玩家当前位置，以及四个角落的撤离点。

主画面不是直接操作整张地图，而是当前所在格子的“房间场景”。每一个房间对应扫雷地图上的一个格子。房间上下左右有门，玩家通过门移动到相邻格子。地图层负责判断风险和路径，房间层负责表现探索、搜刮、战斗和撤离。

一句话 Pitch：

> 你在一座由扫雷格子组成的地牢中醒来，数字告诉你附近有多少危险房间，而真正的选择发生在每一扇门前。

---

## 二、屏幕结构

### 主画面：当前房间

- 显示玩家当前所在的房间。
- 房间最多有四个门：上、下、左、右。
- 门对应扫雷地图上的相邻格子。
- 如果相邻坐标超出地图边界，则该方向没有门。
- 房间内可以放置搜索点、敌人、陷阱、临时道具、撤离装置等表现元素。

### 左上角：扫雷小地图

小地图显示整张扫雷地图，采用经典扫雷信息表达：

- 未探索格：盖住的格子。
- 已探索安全格：显示附近 8 格内的地雷数量。
- 0 格：显示为空白，并可连锁展开。
- 插旗格：玩家标记为疑似危险。
- 玩家当前位置：用明显头像/箭头/高亮框显示。
- 四角撤离点：始终可见，且永远不是地雷。

### 点击放大地图

玩家点击左上角小地图后，进入放大地图界面：

- 放大显示整张扫雷地图。
- 可以更清楚地查看数字、旗标、玩家位置和撤离点。
- 可在放大界面进行标记/取消标记。
- 可在放大界面点击已经经过的安全房间，直接传送回该房间。
- 放大地图不取代房间移动，玩家仍然需要回到房间，通过门实际移动。

---

## 三、地图与房间的关系

每个扫雷格子对应一个房间。

```text
扫雷地图坐标 (x, y)
        ↓
当前房间场景 Room(x, y)
        ↓
上/下/左/右门
        ↓
相邻坐标 Room(x, y - 1 / y + 1 / x - 1 / x + 1)
```

### 房间状态

| 状态 | 地图显示 | 房间含义 |
|------|----------|----------|
| 未探索 | 盖住 | 玩家未进入过 |
| 当前房间 | 玩家标记 | 玩家所在位置 |
| 安全已探索 | 数字/空白 | 可通行，可搜刮，可作为回传目标 |
| 插旗 | 旗标 | 玩家认为危险，默认不建议进入 |
| 地雷 | 隐藏，触发后显示 | 危险房间、埋伏、致命陷阱 |
| 撤离点 | 角落图标 | 可撤离，永不为雷 |

### 移动规则

- 玩家只能通过当前房间的四个门移动。
- 移动方向为 4 邻域，上下左右。
- 扫雷数字仍然按经典规则计算 8 邻域地雷数量。
- 进入未探索房间等价于扫雷中的“翻开格子”。
- 进入地雷房会触发危险事件，第一版可直接判定失败或进入战斗/重伤状态。
- 进入安全房后，小地图显示该格周围地雷数。

### 回传规则

玩家经过的安全房间会成为可回传房间。

- 只能传送到已经进入过的安全房间。
- 不能传送到未探索格、插旗格、地雷格或没有实际到达过的数字格。
- 传送不揭示新格子，也不触发新房间事件。
- 传送后只更新玩家当前位置和当前房间场景。
- 这个机制用于减少重复跑图，让玩家更快回到岔路口、中心区域或已确认的撤离路线。
- 如果玩家已经到达过某个撤离点，也可以传送回该撤离点并选择撤离。

## 四、扫雷生成规则

### 基础规则

- 地图推荐尺寸：15x15 或 21x21。
- 玩家从地图中心出生。
- 四个角分别是撤离点。
- 中心出生点和四个角落撤离点永远不能是地雷。
- 地图必须保证从中心至少有路可以走到四个撤离点。
- 可以有多条路，但至少要有保底可达路线。

### 路径保证

生成地图时，先从中心到四个角各生成一条安全路径，再在剩余格子中放雷。

安全路径格子：

- 不会生成地雷。
- 可以作为玩家撤离保底路线。
- 后续表现上不一定直接暴露给玩家，避免过度破坏扫雷推理。

### 已实现核心模块

当前 Lua 核心已经提供：

- `systems.Minefield`：扫雷地图生成、布雷、数字计算、翻格、插旗、连通性验证。
- `systems.ExtractionRun`：玩家位置、移动、踩雷失败、到达撤离点后撤离。

## 五、搜打撤循环

### 单局目标

1. 从中心出生。
2. 探索房间，读取小地图数字。
3. 搜刮资源，判断危险格。
4. 通过房间门移动到更深区域。
5. 必要时传送回已经经过的安全房间，重新规划路线。
6. 抵达四角任一撤离点。
7. 选择撤离，带走本局收益。

### 风险来源

地雷格在表现层不一定只是“炸弹”，可以对应：

- 埋伏房。
- 高危怪物房。
- 塌陷陷阱。
- 毒气/火焰/电流房。
- Boss 或精英遭遇。

经典扫雷数字表示“周围 8 个房间里有几个高危房间”。

### 搜刮与撤离

- 安全房可以有搜索点。
- 越靠近角落撤离点，资源价值可以更高。
- 玩家随时面临“继续深入”还是“去角落撤离”的选择。
- 四角都是撤离点，玩家可以根据地图判断最近或最安全的撤离路线。

## 六、房间表现方向

### 房间基础元素

- 玩家角色。
- 四方向门。
- 当前房间类型表现。
- 可搜索物件。
- 危险事件或敌人。
- 小地图 UI。

### 门的表现

| 门状态 | 表现 |
|--------|------|
| 可通行 | 门亮起或打开 |
| 地图边界 | 无门或封死 |
| 已探索相邻房 | 稳定门框/有路径痕迹 |
| 未探索相邻房 | 黑暗门口/未知感 |
| 插旗相邻房 | 门上有危险标记 |

### 当前房间信息

进入安全房后，房间可以用环境表现呼应扫雷数字：

- 数字 0：安静、空旷、无威胁感。
- 数字 1-2：轻微危险提示。
- 数字 3-4：明显压迫感。
- 数字 5+：强烈危险氛围。

## 七、第一版范围

### 必做

- [x] 扫雷地图核心生成。
- [x] 中心出生。
- [x] 四角撤离点。
- [x] 保证中心到四角可达。
- [x] 翻格、插旗、数字计算。
- [x] 玩家移动与撤离核心状态。
- [ ] 左上角小地图 UI。
- [ ] 点击放大地图。
- [ ] 传送回已经经过的安全房间。
- [ ] 当前玩家位置显示。
- [ ] 房间场景和四方向门。
- [ ] 通过门进入相邻格。
- [ ] 踩雷/危险房表现。
- [ ] 撤离点房间表现与撤离按钮。

### 暂不做

- 复杂战斗系统。
- 大量房间随机事件。
- 多层地牢。
- 装备成长。
- 联机。

---

## 八、交互原则

- 小地图负责“读信息”，房间负责“做行动”。
- 玩家不能直接在地图上瞬移。
- 玩家只能传送回已经亲自经过的安全房间，不能传送到未知格子。
- 数字必须清楚，符合经典扫雷直觉。
- 玩家当前位置必须始终醒目。
- 撤离点必须清楚可见。
- 保底路径存在，但不要直接告诉玩家完整路线。
- 房间门移动要和地图坐标严格一致，避免玩家迷路。

---

## 九、后续可扩展

- 地雷房不一定立即失败，可以扩展为战斗/受伤/资源损失。
- 不同房间主题可以对应不同危险类型。
- 道具可以提供扫雷能力：探测、排雷、远程翻格、显示一条安全方向。
- 撤离点可以有不同奖励倍率或结算事件。
- 多层地图可做成“每层一张扫雷图”。
